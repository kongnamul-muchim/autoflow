💡 사용 방법

1
📝 상품 설명 상품명과 카테고리를 입력하면 AI가 최적화된 제목, 설명, 키워드, USP를 자동 생성합니다.
2
📊 마케팅 리포트 Cafe24, Meta, Naver 등 여러 채널의 데이터를 수집하여 AI가 요약 리포트와 인사이트를 만들어줍니다.
3
🔄 데이터 동기화 외부 플랫폼(Cafe24↔Meta↔Naver) 간 상품/데이터를 자동으로 동기화합니다. (현재 Mock 모드)
4
⚙️ 파이프라인 여러 자동화 태스크를 파이프라인으로 묶어 순차 실행합니다. 배치 작업 자동화에 사용하세요.
