1. `WebController.ts` 에 `<<<<<<< Updated upstream` 머지 충돌 마커가 남아 코드가 빌드 불가 상태였고,

3. `DEEPSEEK_API_BASE` 에 실제로는 Gemini 엔드포인트가 들어 있어 변수명과 대상이 어긋나 있었다.

## 변경

### 프로바이더 결정을 한 곳으로

`src/infrastructure/ai/providerPresets.ts` — 프리셋 표(anthropic, openai, deepseek, gemini,
openrouter, groq, ollama)에서 base URL·기본 모델·프로토콜을 결정한다.
변수는 `AI_PROVIDER` / `AI_API_KEY` / `AI_MODEL` / `AI_BASE_URL` 4개로 고정.
예전 변수명도 계속 읽되 새 이름이 우선한다.

### 불일치 감지

`AI_PROVIDER` 와 base 호스트를 대조해 어긋나면 기동 로그·`/api/health`(aiWarning)·화면에 남긴다.
실제 사고를 그대로 재현해 확인했다.

```
AI_PROVIDER=deepseek + DEEPSEEK_API_BASE=https://generativelanguage.googleapis.com/v1beta/openai/
→ ⚠️ AI_PROVIDER=deepseek 인데 base host 가 generativelanguage.googleapis.com 입니다 (이 주소는 gemini 것 같습니다)
```

### 방문자 자기 키(BYOK)

- 헤더 `X-AI-Key` / `X-AI-Provider` / `X-AI-Model` 을 `AsyncLocalStorage` 로 요청 단위에만 주입.
- 저장하지 않는다. 로그는 `maskKey()` 로 마스킹(`tes****1234`).
- **base URL 은 헤더로 받지 않는다** — 클라이언트가 base 를 정하면 SSRF 통로가 된다.
- 응답 헤더 `X-AI-Mode` / `X-AI-Provider` / `X-AI-Key-Source` 로 이번 응답의 출처를 기계가 확인 가능.
- 키는 브라우저 `sessionStorage` 에만. 탭을 닫으면 사라진다.

### 그 밖에 같이 고친 것

- LLM 응답이 `\`\`\`json` 펜스로 와서 파싱에 실패하던 문제 → `parseJsonObject` (펜스/앞뒤 설명/문자열 배열 대응).
- `.mock-notice[hidden]` 규칙 추가 — `display:flex` 가 `hidden` 을 덮어써 live 인데도 "샘플 모드" 안내문이 보였다.
- 카드의 `MOCK` 태그를 서버 모드에 따라 `LIVE`/`MOCK`/`FALLBACK` 으로.
- 429 를 일반 오류와 구분해 로그에 남긴다(쿼터 소진 vs 설정 오류).
